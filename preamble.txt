# 5. Seed–invariant compatibility heuristic

This should happen before prompting.

The purpose is to route each seed to:

- `strict_paraphrase`
- `grounded_rewrite`
- `skip`

---

## Compatibility scoring idea

Use three signals:

### A. Identifier support score
How many candidate model-specific terms in the seed are supported by the invariant?

### B. Absent concept hit count
Does the seed contain concepts known not to exist in this model?

### C. Topic grounding score
Does the seed overlap with `model_summary`, `concepts_present`, or corpus examples for that model?

---

## Lightweight heuristic

### Step 1: Extract candidate tokens
From question and answer:

- backticked identifiers
- hyphenated words
- variable-like words with `?`
- widget-like phrases
- repeated noun phrases
- quoted strings that look like state names

Examples from your bad seed:
- `state`
- `patrolling`
- `chasing`
- `herding`
- `herd-radius`
- `[state] of turtles`

---

## Step 2: Normalize
Lowercase, strip punctuation, singularize obvious plurals, preserve exact identifier forms too.

---

## Step 3: Compare against sets

Let:

- `M` = model identifiers
- `C+` = present concepts
- `C-` = absent concepts
- `G` = global NetLogo terms

Then compute:

- `supported_identifiers = extracted ∩ (M ∪ G)`
- `unsupported_identifiers = extracted - (M ∪ G)`
- `absent_hits = phrases matched in C-`
- `present_hits = phrases matched in C+ or model_summary`

---

## Routing rule

### Strict paraphrase
Use if:

- `absent_hits == 0`
- unsupported identifier ratio is low
- some present grounding exists

Example threshold:
```python
if absent_hits == 0 and unsupported_ratio <= 0.15 and present_hits >= 1:
    route = "strict_paraphrase"
```

### Grounded rewrite
Use if:

- some unsupported terms exist
- but seed still seems locally related to the model

Example:
```python
elif absent_hits <= 2 and present_hits >= 1:
    route = "grounded_rewrite"
```

### Skip
Use if:

- many absent hits
- topic appears from another model
- no grounding signal

Example:
```python
else:
    route = "skip"
```

---

## Pseudocode

```python
def route_seed(seed_q, seed_a, invariant, global_allow):
    text = f"{seed_q}\n{seed_a}"

    extracted = extract_candidate_terms(text)
    model_terms = (
        set(invariant["procedures"]) |
        set(invariant["globals"]) |
        set(invariant["widgets"]) |
        set([b["plural"] for b in invariant["breeds"]]) |
        set([b["singular"] for b in invariant["breeds"]])
    )
    global_terms = set(global_allow["netlogo_general_terms"]) | set(global_allow["netlogo_primitives"])

    supported = [t for t in extracted if t in model_terms or t in global_terms]
    unsupported = [t for t in extracted if t not in model_terms and t not in global_terms]

    absent_hits = match_phrases(text, invariant["absent_concepts"])
    present_hits = match_phrases(text, invariant["concepts_present"]) + match_summary_overlap(text, invariant["model_summary"])

    unsupported_ratio = len(unsupported) / max(1, len(extracted))

    if len(absent_hits) == 0 and unsupported_ratio <= 0.15 and present_hits >= 1:
        return "strict_paraphrase"
    elif len(absent_hits) <= 2 and present_hits >= 1:
        return "grounded_rewrite"
    else:
        return "skip"
```

# 4. Python audit script

Below is a standard-library-only script skeleton that:

- loads model profiles
- loads Q&A records
- groups by model
- extracts candidate terms
- compares them to hard invariants
- writes per-model audit reports

It assumes you already have records shaped like:

```json
{
  "model_name": "shepherds",
  "question": "...",
  "answer": "...",
  "source": "corpus"
}
```

If `synth_plan.json` only gives IDs, join the seed text to records first.

```python
import json
import re
from collections import Counter, defaultdict
from pathlib import Path
from typing import Dict, List, Any

BACKTICK_RE = re.compile(r"`([^`]+)`")
BRACKET_RE = re.compile(r"\[([^\]]+)\]")
QUOTE_RE = re.compile(r'"([^"]+)"|\'([^\']+)\'')
IDLIKE_RE = re.compile(r"\b[a-zA-Z][a-zA-Z0-9-]*\??\b")

PHRASE_KEYWORDS = {
    "state", "states", "variable", "variables", "procedure", "procedures",
    "reporter", "reporters", "slider", "monitor", "plot", "threshold",
    "radius", "timer", "cooldown", "duration", "efficiency", "density",
    "search", "herd", "herding", "shepherd", "sheep", "speed", "count"
}

STOPWORDS = {
    "the", "a", "an", "of", "to", "for", "in", "on", "at", "by", "with",
    "and", "or", "is", "are", "was", "were", "be", "as", "from", "that",
    "this", "these", "those", "it", "its", "their", "them", "what", "how",
    "why", "when", "where", "which", "do", "does", "did", "can", "could",
    "would", "should", "into", "about", "than", "then", "if", "we", "you"
}


def load_json(path: str) -> Any:
    with open(path, "r", encoding="utf-8") as f:
        return json.load(f)


def load_jsonl(path: str) -> List[Dict[str, Any]]:
    rows = []
    with open(path, "r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                rows.append(json.loads(line))
    return rows


def dump_json(obj: Any, path: str) -> None:
    Path(path).parent.mkdir(parents=True, exist_ok=True)
    with open(path, "w", encoding="utf-8") as f:
        json.dump(obj, f, ensure_ascii=False, indent=2)


def norm(s: str) -> str:
    return re.sub(r"\s+", " ", s.strip().lower())


def hard_term_set(model_profile: Dict[str, Any]) -> set:
    hard = model_profile["hard"]
    terms = set()

    for key in ["procedures", "globals", "turtles_own", "patches_own", "links_own", "widgets", "string_literals"]:
        for x in hard.get(key, []):
            terms.add(norm(x))

    for breed in hard.get("breeds", []):
        if isinstance(breed, dict):
            if "singular" in breed:
                terms.add(norm(breed["singular"]))
            if "plural" in breed:
                terms.add(norm(breed["plural"]))
        else:
            terms.add(norm(breed))

    for _, own_vars in hard.get("breed_own", {}).items():
        for x in own_vars:
            terms.add(norm(x))

    return terms


def global_term_set(global_netlogo: Dict[str, Any]) -> set:
    terms = set()
    for key in ["general_terms", "primitives"]:
        for x in global_netlogo.get(key, []):
            terms.add(norm(x))
    return terms


def extract_exact_terms(text: str) -> Counter:
    out = Counter()

    # backticks
    for t in BACKTICK_RE.findall(text):
        out[norm(t)] += 1

    # bracketed single-token reporter references like [state]
    for t in BRACKET_RE.findall(text):
        t = t.strip()
        if re.fullmatch(r"[A-Za-z][A-Za-z0-9-]*\??", t):
            out[norm(t)] += 1

    # identifier-like tokens that look model-specific
    for t in IDLIKE_RE.findall(text):
        if "-" in t or t.endswith("?"):
            out[norm(t)] += 1

    return out


def extract_phrase_candidates(text: str, min_n: int = 2, max_n: int = 4) -> Counter:
    tokens = [norm(t) for t in IDLIKE_RE.findall(text)]
    tokens = [t for t in tokens if t not in STOPWORDS]

    out = Counter()

    # quoted phrases
    for g1, g2 in QUOTE_RE.findall(text):
        phrase = norm(g1 or g2)
        if phrase and 1 <= len(phrase.split()) <= 4:
            out[phrase] += 1

    # keyword-centered ngrams
    for n in range(min_n, max_n + 1):
        for i in range(len(tokens) - n + 1):
            gram = tokens[i:i+n]
            if any(tok in PHRASE_KEYWORDS for tok in gram):
                phrase = " ".join(gram)
                out[phrase] += 1

    return out


def find_absent_hits(text: str, absent_concepts: List[str]) -> Counter:
    t = norm(text)
    hits = Counter()
    for phrase in absent_concepts:
        p = norm(phrase)
        if p and p in t:
            hits[p] += 1
    return hits


def short_example(record: Dict[str, Any], max_len: int = 220) -> Dict[str, str]:
    q = record.get("question", "")[:max_len]
    a = record.get("answer", "")[:max_len]
    return {
        "source": record.get("source", "unknown"),
        "question": q,
        "answer": a
    }


def analyze_model_records(model_name: str, records: List[Dict[str, Any]], profile: Dict[str, Any], global_terms: set) -> Dict[str, Any]:
    model_terms = hard_term_set(profile)
    absent_concepts = profile.get("negative", {}).get("absent_concepts", [])

    supported_terms = Counter()
    unsupported_terms = Counter()
    phrase_candidates = Counter()
    absent_hits = Counter()

    examples_supported = defaultdict(list)
    examples_unsupported = defaultdict(list)
    examples_absent = defaultdict(list)

    source_counts = Counter()

    for rec in records:
        source_counts[rec.get("source", "unknown")] += 1
        text = f'{rec.get("question", "")}\n{rec.get("answer", "")}'

        exact_terms = extract_exact_terms(text)
        phrases = extract_phrase_candidates(text)
        hits = find_absent_hits(text, absent_concepts)

        for term, c in exact_terms.items():
            if term in model_terms or term in global_terms:
                supported_terms[term] += c
                if len(examples_supported[term]) < 3:
                    examples_supported[term].append(short_example(rec))
            else:
                unsupported_terms[term] += c
                if len(examples_unsupported[term]) < 3:
                    examples_unsupported[term].append(short_example(rec))

        for phrase, c in phrases.items():
            phrase_candidates[phrase] += c

        for phrase, c in hits.items():
            absent_hits[phrase] += c
            if len(examples_absent[phrase]) < 3:
                examples_absent[phrase].append(short_example(rec))

    parser_miss_candidates = [
        term for term, c in unsupported_terms.most_common()
        if c >= 3 and term not in absent_concepts
    ]

    report = {
        "model_name": model_name,
        "record_counts": dict(source_counts),
        "top_supported_terms": [
            {"term": t, "count": c, "examples": examples_supported[t]}
            for t, c in supported_terms.most_common(30)
        ],
        "top_unsupported_terms": [
            {"term": t, "count": c, "examples": examples_unsupported[t]}
            for t, c in unsupported_terms.most_common(50)
        ],
        "top_absent_hits": [
            {"phrase": p, "count": c, "examples": examples_absent[p]}
            for p, c in absent_hits.most_common(30)
        ],
        "top_phrase_candidates": [
            {"phrase": p, "count": c}
            for p, c in phrase_candidates.most_common(100)
        ],
        "parser_miss_candidates": parser_miss_candidates[:30]
    }

    return report


def group_records_by_model(records: List[Dict[str, Any]]) -> Dict[str, List[Dict[str, Any]]]:
    grouped = defaultdict(list)
    for rec in records:
        model = rec.get("model_name")
        if model:
            grouped[model].append(rec)
    return grouped


def main(model_profiles_path: str, records_jsonl_path: str, out_dir: str) -> None:
    profiles = load_json(model_profiles_path)
    records = load_jsonl(records_jsonl_path)

    global_terms = global_term_set(profiles.get("global_netlogo", {}))
    grouped = group_records_by_model(records)

    all_reports = {}

    for model_name, profile in profiles["models"].items():
        model_records = grouped.get(model_name, [])
        report = analyze_model_records(model_name, model_records, profile, global_terms)
        all_reports[model_name] = report
        dump_json(report, str(Path(out_dir) / f"{model_name}.json"))

    dump_json(all_reports, str(Path(out_dir) / "_all_models.json"))


if __name__ == "__main__":
    # Example:
    # python build_model_audit.py model_profiles.json all_records.jsonl model_audit_reports
    import sys
    main(sys.argv[1], sys.argv[2], sys.argv[3])
```

# 6. How to use the audit output

For each model report, review:

## `top_unsupported_terms`
Ask:

- is this a parser miss?
- is this a soft alias?
- is this a drift term?

## `top_absent_hits`
These are your common hallucination themes.

## `parser_miss_candidates`
These are unsupported terms frequent enough to deserve inspection.

# 7. Updating `model_profiles.json`

After review, update per model:

## If term is truly in source
Move it into `hard`

## If term is a useful paraphrase
Put it in:

- `soft.concepts_present`
- or `soft.concept_aliases`

## If term is false but recurring
Put it in:

- `negative.absent_concepts`

# 8. Seed routing function

Once you have `model_profiles.json`, route each seed before prompting.

Here is a lightweight version.

```python
def route_seed(question: str, answer: str, model_profile: dict, global_terms: set) -> dict:
    text = f"{question}\n{answer}"

    model_terms = hard_term_set(model_profile)
    absent_concepts = model_profile.get("negative", {}).get("absent_concepts", [])
    concepts_present = [norm(x) for x in model_profile.get("soft", {}).get("concepts_present", [])]
    model_summary = norm(model_profile.get("soft", {}).get("model_summary", ""))

    exact_terms = extract_exact_terms(text)
    extracted = list(exact_terms.keys())

    supported = [t for t in extracted if t in model_terms or t in global_terms]
    unsupported = [t for t in extracted if t not in model_terms and t not in global_terms]

    absent_hits = list(find_absent_hits(text, absent_concepts).keys())

    tnorm = norm(text)
    present_hits = []
    for c in concepts_present:
        if c in tnorm:
            present_hits.append(c)
    if model_summary and any(tok in model_summary for tok in extracted):
        present_hits.append("summary_overlap")

    unsupported_ratio = len(unsupported) / max(1, len(extracted))

    if len(absent_hits) == 0 and unsupported_ratio <= 0.15 and len(present_hits) >= 1:
        route = "strict_paraphrase"
    elif len(absent_hits) <= 2 and (len(present_hits) >= 1 or unsupported_ratio <= 0.5):
        route = "grounded_rewrite"
    else:
        route = "skip"

    return {
        "route": route,
        "supported_terms": supported,
        "unsupported_terms": unsupported,
        "absent_hits": absent_hits,
        "present_hits": present_hits,
        "unsupported_ratio": unsupported_ratio
    }
```
