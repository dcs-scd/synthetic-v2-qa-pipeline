# New framing: two valid regimes

For `rebellion`, and likely many other models, there are really two kinds of synthetic data.

## Regime A: model-faithful
Questions and answers about the actual source model.

Examples:
- how `grievance` works
- effect of `government-legitimacy`
- behavior of `cops`
- active/jail dynamics

In this regime:
- use source-derived hard invariants
- reject unsupported mechanisms

## Regime B: model-anchored extension
Questions and answers that start from the original model but propose coherent modifications or generalizations.

Examples:
- add broadcast media
- add social links
- split active/inactive into multiple states
- add long-range ties
- optimize large-network spread

In this regime:
- the seed may introduce new variables/concepts
- those concepts are allowed **if they are framed as extensions**
- they should not be rejected just because they are absent from the original code

This is what your current system is missing.

- unrelated
- not anchored
- nonsensical mechanism

The validator should target **bad hallucination**, not coherent extension.

# 3. Updated Gate 2 validation logic for `core` vs `anchored_extension`

This is the biggest structural change.

---

## 3.1 Current problem

Your current Gate 2 appears to do:

- extract backticked identifiers
- reject anything not in:
  - procedures
  - variables
  - breeds
  - widgets

That is fine only for strict source-faithful generation.

It is too narrow for coherent extension mode.

---

## 3.2 New Gate 2 should be mode-aware

## Mode A: `core_paraphrase`
Allowed identifiers:
- core identifiers
- global NetLogo terms

Forbidden:
- extension identifiers
- unsupported concepts framed as existing mechanisms

## Mode B: `anchored_extension`
Allowed identifiers:
- core identifiers
- approved extension identifiers for that model
- global NetLogo terms

Additional requirements:
- extension identifiers must be framed as additions/modifications
- answer must remain anchored to the base model

---

## 3.3 New validation checks

For every generated Q&A, run these checks.

### Check 1: identifier allowlist
Extract backticked identifiers.

#### In `core_paraphrase`
Every backticked identifier must be in:
- `core`
- or global NetLogo allowlist

Else reject:
- `UNKNOWN_CORE_IDENTIFIER`

#### In `anchored_extension`
Every backticked identifier must be in:
- `core`
- or `approved_extension_identifiers`
- or global NetLogo allowlist

Else reject:
- `UNAPPROVED_EXTENSION_IDENTIFIER`

---

### Check 2: extension framing
Only in `anchored_extension`.

If any extension identifier appears, require explicit framing.

Good framing patterns:
- “extend the original model”
- “add”
- “introduce”
- “modify”
- “in an extended version”
- “replace the original”
- “not part of the original code”

If extension identifiers appear without framing, reject:
- `EXTENSION_REQUIRES_FRAMING`

---

### Check 3: base-model misrepresentation
Only in `anchored_extension`.

Reject if the answer implies extension identifiers already exist in the base model.

Bad patterns:
- “the model uses `rebellion-state`”
- “the existing code tracks `media-influence`”
- “the built-in network layer”
- “the original model includes `homophily-index`”

Reject:
- `BASE_MODEL_MISREPRESENTATION`

---

### Check 4: minimum anchor requirement
Only in `anchored_extension`.

Require the answer to reference the base model by including at least one of:
- a core identifier
- a strong core concept from `model_summary`

For `rebellion`, examples:
- `active?`
- `grievance`
- `estimated-arrest-probability`
- `government-legitimacy`
- `cops`
- `jail-term`
- `vision`
- “original rebellion model”

If not, reject:
- `INSUFFICIENT_CORE_ANCHOR`

This prevents extension answers from drifting into generic social modeling.

---

### Check 5: unsupported concept scan
In both modes.

Reject if the answer introduces concepts that are neither:
- core
- approved extension concepts
- general NetLogo concepts
- generic scientific language

Examples to reject:
- unrelated domain drift
- incoherent mechanism drift

Reject:
- `UNSUPPORTED_CONCEPT`

---

Use these codes:

- `UNKNOWN_CORE_IDENTIFIER`

- `EXTENSION_REQUIRES_FRAMING`

## 3.5 Pseudocode for the new Gate 2

```python
def validate_identifiers_and_extensions(
    question: str,
    answer: str,
    mode: str,
    model_profile: dict,
    global_allow: set
):
    text = question + "\n" + answer

    core_ids = build_core_identifier_set(model_profile["core"])
    ext_ids = build_extension_identifier_set(model_profile.get("extensions", {}))
    ext_concepts = build_extension_concept_set(model_profile.get("extensions", {}))
    framing_cues = set(model_profile.get("extensions", {}).get("framing_cues", []))

    backticked = extract_backticked_identifiers(text)
    plain_concepts = extract_candidate_concepts(text)

    used_core = [x for x in backticked if x in core_ids]
    used_ext = [x for x in backticked if x in ext_ids]
    unknown = [x for x in backticked if x not in core_ids and x not in ext_ids and x not in global_allow]

    if mode == "core_paraphrase":
        if unknown:
            return reject("UNKNOWN_CORE_IDENTIFIER", unknown)

        if used_ext:
            return reject("UNAPPROVED_EXTENSION_IDENTIFIER", used_ext)

        unsupported = [
            c for c in plain_concepts
            if is_model_specific(c)
            and c not in ext_concepts
            and c not in core_ids
            and c not in global_allow
        ]
        # optional stricter scan here
        return accept()

    elif mode == "anchored_extension":
        if unknown:
            return reject("UNAPPROVED_EXTENSION_IDENTIFIER", unknown)

        if used_ext:
            if not has_extension_framing(answer, framing_cues):
                return reject("EXTENSION_REQUIRES_FRAMING", used_ext)

            if implies_base_model_contains_extensions(answer, used_ext):
                return reject("BASE_MODEL_MISREPRESENTATION", used_ext)

        if not has_core_anchor(text, core_ids, model_profile["core"].get("model_summary", "")):
            return reject("INSUFFICIENT_CORE_ANCHOR", [])

        unsupported = [
            c for c in plain_concepts
            if is_suspicious_model_specific(c)
            and c not in ext_concepts
            and c not in core_ids
            and c not in ext_ids
            and c not in global_allow
        ]
        if unsupported:
            return reject("UNSUPPORTED_CONCEPT", unsupported[:10])

        return accept()

    else:
        return reject("UNKNOWN_MODE", [mode])
```

# 1. `route_seed()` classifier

The classifier’s job is to decide whether a seed should be treated as:

- `core_paraphrase`
- `core_repair`
- `anchored_extension`
- `skip`

## Why 4 labels instead of 2

You asked for core vs extension, but in practice a 4-way split works better:

- **`core_paraphrase`**: seed is already source-faithful
- **`core_repair`**: mostly source-faithful, but needs small cleanup
- **`anchored_extension`**: coherent model extension
- **`skip`**: incoherent or off-theme

If you want only two runtime modes, you can map:

- `core_paraphrase` + `core_repair` → core-mode prompt
- `anchored_extension` → extension-mode prompt
- `skip` → reject

---

### B. Extension-family support

### C. Explicit extension intent
Words like:

- extend
- modify
- introduce
- layer
- network
- broadcast
- long-range
- optimize

### D. Unknown unsupported terms
If the seed contains lots of model-specific terms that are in neither core nor approved extensions, it may need skipping.

## 1.3 Python implementation

```python
import re
from collections import Counter

BACKTICK_RE = re.compile(r"`([^`]+)`")
IDLIKE_RE = re.compile(r"\b[a-zA-Z][a-zA-Z0-9-]*\??\b")

GLOBAL_EXTENSION_CUES = {
    "add", "extend", "modify", "introduce", "layer", "network",
    "broadcast", "media", "friends", "leader", "leaders",
    "long-range", "small-world", "optimize", "optimization",
    "5000-agent", "state", "diagram", "homophily", "cluster"
}

STOPWORDS = {
    "the", "a", "an", "of", "to", "for", "in", "on", "at", "by", "with",
    "and", "or", "is", "are", "was", "were", "be", "as", "from", "that",
    "this", "these", "those", "it", "its", "their", "them", "what", "how",
    "why", "when", "where", "which", "do", "does", "did", "can", "could",
    "would", "should", "into", "about", "than", "then", "if", "we", "you",
    "model", "netlogo"
}

def norm(s: str) -> str:
    return re.sub(r"\s+", " ", s.strip().lower())

def core_identifier_set(profile: dict) -> set:
    core = profile["core"]
    out = set()
    for key in ["procedures", "variables", "breeds", "widgets"]:
        for x in core.get(key, []):
            out.add(norm(x))
    return out

def family_lookup(profile: dict):
    fams = {}
    for fam in profile.get("extensions", {}).get("families", []):
        fams[fam["name"]] = {
            "concepts": {norm(x) for x in fam.get("concepts", [])},
            "identifiers": {norm(x) for x in fam.get("identifiers", [])},
            "rules": fam.get("rules", [])
        }
    return fams

def extract_terms(text: str) -> set:
    text_n = norm(text)
    terms = set()

    for x in BACKTICK_RE.findall(text):
        terms.add(norm(x))

    for x in IDLIKE_RE.findall(text):
        x = norm(x)
        if x not in STOPWORDS:
            terms.add(x)

    return terms

def count_phrase_hits(text: str, phrases: set) -> int:
    t = norm(text)
    hits = 0
    for p in phrases:
        if p and p in t:
            hits += 1
    return hits

def has_extension_intent(text: str) -> bool:
    terms = extract_terms(text)
    return any(t in GLOBAL_EXTENSION_CUES for t in terms)

def route_seed(seed_q: str, seed_a: str, profile: dict) -> dict:
    text = f"{seed_q}\n{seed_a}"
    text_n = norm(text)

    core_ids = core_identifier_set(profile)
    fams = family_lookup(profile)

    terms = extract_terms(text)

    core_hits = sorted([t for t in terms if t in core_ids])

    family_scores = {}
    family_matches = {}
    for name, spec in fams.items():
        id_hits = [t for t in terms if t in spec["identifiers"]]
        concept_score = count_phrase_hits(text_n, spec["concepts"])
        score = len(id_hits) + concept_score
        family_scores[name] = score
        family_matches[name] = {
            "identifier_hits": sorted(id_hits),
            "concept_score": concept_score
        }

    best_family = None
    best_family_score = 0
    if family_scores:
        best_family = max(family_scores, key=family_scores.get)
        best_family_score = family_scores[best_family]

    approved_ext_ids = set()
    for spec in fams.values():
        approved_ext_ids |= spec["identifiers"]

    unknown_terms = sorted([
        t for t in terms
        if t not in core_ids and t not in approved_ext_ids
    ])

    ext_intent = has_extension_intent(text)

    # Route logic
    if best_family_score >= 2 or (ext_intent and best_family_score >= 1):
        route = "anchored_extension"
        family = best_family
    elif len(core_hits) >= 2 and not ext_intent and best_family_score == 0:
        route = "core_paraphrase"
        family = None
    elif len(core_hits) >= 1 and best_family_score == 0:
        route = "core_repair"
        family = None
    else:
        route = "skip"
        family = None

    return {
        "route": route,
        "family": family,
        "core_hits": core_hits[:25],
        "best_family_score": best_family_score,
        "family_scores": family_scores,
        "family_matches": family_matches,
        "extension_intent": ext_intent,
        "unknown_terms_sample": unknown_terms[:25]
    }
```

```python
def comma_join(xs):
    return ", ".join(xs)

def render_core_block(profile: dict) -> str:
    core = profile["core"]
    return (

        f"{core.get('model_summary', '')}\n\n"
        f"CORE MODEL INVARIANTS:\n"
        f"- procedures: {comma_join(core.get('procedures', []))}\n"
        f"- variables: {comma_join(core.get('variables', []))}\n"
        f"- breeds: {comma_join(core.get('breeds', []))}\n"
        f"- widgets: {comma_join(core.get('widgets', []))}\n"
    )

def get_family(profile: dict, family_name: str) -> dict:
    for fam in profile.get("extensions", {}).get("families", []):
        if fam["name"] == family_name:
            return fam
    return {}

def build_core_repair_prompt(seed: dict, profile: dict) -> str:
    return f"""

Hard rules:

Priority order:
1. Core model correctness
2. Preserve as much of the seed's educational intent as possible
3. Repair unsupported specificity
4. Style

CONTEXT:
- model_name: {seed["model_name"]}
- level: {seed["level"]}
- tier: {seed["tier"]}
- mode: core_repair

Style:
- scientific coaching
- include exactly one hypothesis
- include exactly one experiment
- include exactly one limitation

{render_core_block(profile)}

TASK:
Repair and rewrite the seed into the nearest technically correct source-faithful Q&A for the original model.
Do not preserve unsupported identifiers literally.

SEED QUESTION:
{seed["seed_q"]}

SEED ANSWER:
{seed["seed_a"]}

OUTPUT:
Return ONE JSON object only:
{{"question": "...", "answer": "..."}}
or
{{"skip":"SEED_CONFLICT"}}
""".strip()

def build_extension_prompt(seed: dict, profile: dict, family_name: str) -> str:
    fam = get_family(profile, family_name)
    ext_rules = profile.get("extensions", {}).get("general_rules", [])
    fam_rules = fam.get("rules", [])
    framing_cues = profile.get("extensions", {}).get("framing_cues", [])

    return f"""
You generate high-quality synthetic training data for NetLogo Q&A.

Hard rules:
- Output JSON only: {{"question": "...", "answer": "..."}}
- No markdown fences, no preamble, no commentary.
- Preserve technical correctness.
- Distinguish clearly between the original model and proposed extensions.
- Core identifiers may be backticked.
- Extension identifiers may be backticked only if they are approved below.
- Do not present extension identifiers as if they already exist in the original source code.

Priority order:
1. Technical correctness
2. Preserve the seed's educational intent
3. Stay anchored to the original model
4. Style

CONTEXT:
- model_name: {seed["model_name"]}
- level: {seed["level"]}
- tier: {seed["tier"]}
- mode: anchored_extension
- extension_family: {family_name}

Style:
- scientific coaching
- include exactly one hypothesis
- include exactly one experiment
- include exactly one limitation

{render_core_block(profile)}

ALLOWED EXTENSION FAMILY:
- {family_name}

ALLOWED EXTENSION CONCEPTS:
- {comma_join(fam.get("concepts", []))}

ALLOWED EXTENSION IDENTIFIERS:
- {comma_join(fam.get("identifiers", []))}

FAMILY RULES:
- {"\n- ".join(fam_rules) if fam_rules else "None"}

GENERAL EXTENSION RULES:
- {"\n- ".join(ext_rules) if ext_rules else "None"}

GOOD FRAMING CUES:
- {"\n- ".join(framing_cues) if framing_cues else "None"}

TASK:
Create a natural variant of the seed that stays anchored to the original model while allowing a coherent extension in the approved family above.

SEED QUESTION:
{seed["seed_q"]}

SEED ANSWER:
{seed["seed_a"]}

OUTPUT:
Return ONE JSON object only: {{"question": "...", "answer": "..."}}
""".strip()

def build_prompt(seed: dict, profile: dict, route_result: dict) -> str:
    route = route_result["route"]

    if route == "core_paraphrase":
        return build_core_prompt(seed, profile)
    elif route == "core_repair":
        return build_core_repair_prompt(seed, profile)
    elif route == "anchored_extension":
        return build_extension_prompt(seed, profile, route_result["family"])
    else:
        raise ValueError("Seed should be skipped; no prompt should be built.")
```

# Mode-aware Gate 2 validator

```python
import re
from typing import Dict, List, Set, Any


BACKTICK_RE = re.compile(r"`([^`]+)`")
WORD_RE = re.compile(r"\b[a-zA-Z][a-zA-Z0-9-]*\??\b")
SENTENCE_SPLIT_RE = re.compile(r"(?<=[.!?])\s+|\n+")

STOPWORDS = {
    "the", "a", "an", "of", "to", "for", "in", "on", "at", "by", "with",
    "and", "or", "is", "are", "was", "were", "be", "as", "from", "that",
    "this", "these", "those", "it", "its", "their", "them", "what", "how",
    "why", "when", "where", "which", "do", "does", "did", "can", "could",
    "would", "should", "into", "about", "than", "then", "if", "we", "you",
    "your", "our", "they", "he", "she", "i", "my", "me", "his", "her",
    "them", "also", "just", "not", "only", "very", "more", "less", "same",
    "different", "new", "old", "model", "netlogo"
}

DEFAULT_GLOBAL_ALLOW = {
    "ticks", "tick", "turtles", "patches", "links", "behaviorspace",
    "monitor", "plot", "reporter", "button", "chooser", "slider",
    "switch", "world", "agent", "agents", "ask", "count", "mean",
    "sum", "min", "max", "distance", "with", "of", "one-of", "n-of",
    "if", "ifelse", "let", "set"
}


def norm(s: str) -> str:
    return re.sub(r"\s+", " ", s.strip().lower())


def split_sentences(text: str) -> List[str]:
    return [x.strip() for x in SENTENCE_SPLIT_RE.split(text) if x.strip()]


def extract_backticked_identifiers(text: str) -> List[str]:
    return [norm(x) for x in BACKTICK_RE.findall(text)]


def extract_words(text: str) -> List[str]:
    return [norm(x) for x in WORD_RE.findall(text)]


def summary_keywords(summary: str) -> Set[str]:
    kws = set()
    for w in extract_words(summary):
        if w not in STOPWORDS and len(w) >= 5:
            kws.add(w)
    return kws


def build_core_identifier_set(core: Dict[str, Any]) -> Set[str]:
    out = set()

    for key in ["procedures", "variables", "breeds", "widgets"]:
        for x in core.get(key, []):
            out.add(norm(x))

    return out


def get_family(profile: Dict[str, Any], family_name: str) -> Dict[str, Any]:
    for fam in profile.get("extensions", {}).get("families", []):
        if fam.get("name") == family_name:
            return fam
    return {}


def all_extension_identifiers(profile: Dict[str, Any]) -> Set[str]:
    out = set()
    for fam in profile.get("extensions", {}).get("families", []):
        for x in fam.get("identifiers", []):
            out.add(norm(x))
    return out


def family_identifier_set(profile: Dict[str, Any], family_name: str) -> Set[str]:
    fam = get_family(profile, family_name)
    return {norm(x) for x in fam.get("identifiers", [])}


def all_extension_concepts(profile: Dict[str, Any]) -> Set[str]:
    out = set()
    for fam in profile.get("extensions", {}).get("families", []):
        for x in fam.get("concepts", []):
            out.add(norm(x))
    return out


def family_concept_set(profile: Dict[str, Any], family_name: str) -> Set[str]:
    fam = get_family(profile, family_name)
    return {norm(x) for x in fam.get("concepts", [])}


def get_framing_cues(profile: Dict[str, Any]) -> Set[str]:
    return {norm(x) for x in profile.get("extensions", {}).get("framing_cues", [])}


def get_disallowed_themes(profile: Dict[str, Any]) -> Set[str]:
    return {norm(x) for x in profile.get("extensions", {}).get("disallowed_unanchored_themes", [])}


def contains_phrase(text: str, phrase: str) -> bool:
    return norm(phrase) in norm(text)


def find_present_phrases(text: str, phrases: Set[str]) -> List[str]:
    t = norm(text)
    hits = []
    for p in phrases:
        if p and p in t:
            hits.append(p)
    return sorted(set(hits))


def has_extension_framing(answer: str, profile: Dict[str, Any]) -> bool:
    a = norm(answer)
    framing_cues = get_framing_cues(profile)

    if any(cue in a for cue in framing_cues):
        return True

    # fallback generic cues
    generic = [
        "extend the original model",
        "extend the model",
        "you could add",
        "you could introduce",
        "one extension is",
        "if you modify the model",
        "in an extended version",
        "beyond the original code",
        "as an extension",
        "replace the original",
        "refine the original"
    ]
    return any(x in a for x in generic)


def implies_base_model_contains_extensions(answer: str, used_extension_ids: Set[str]) -> List[str]:
    """
    Returns a list of extension identifiers that are misrepresented as already existing in the base model.
    """
    bad_hits = []
    sentences = split_sentences(answer)

    bad_cues = [
        "the model already",
        "the original model already",
        "the base model already",
        "already uses",
        "already tracks",
        "already contains",
        "already includes",
        "already has",
        "the existing code",
        "the original code",
        "built-in",
        "currently defined",
        "is defined in the model",
        "is tracked in the model",
        "is in the original model",
        "the model uses",
        "the model tracks",
        "the model contains",
        "the model includes",
        "the model has"
    ]

    safe_cues = [
        "you could add",
        "you could introduce",
        "extend the model",
        "extend the original model",
        "in an extended version",
        "as an extension",
        "if you modify the model",
        "not part of the original code",
        "beyond the original code",
        "replace the original"
    ]

    for sent in sentences:
        s = norm(sent)
        if any(safe in s for safe in safe_cues):
            continue

        for ext_id in used_extension_ids:
            if ext_id in s and any(bad in s for bad in bad_cues):
                bad_hits.append(ext_id)

    return sorted(set(bad_hits))


def has_core_anchor(text: str, core_ids: Set[str], model_summary: str) -> bool:
    t = norm(text)

    # Direct core-id anchor
    for cid in core_ids:
        if cid in t:
            return True

    # Explicit anchoring language
    anchor_phrases = [
        "original model",
        "base model",
        "original rebellion model",
        "extend the original model",
        "original code"
    ]
    if any(p in t for p in anchor_phrases):
        return True

    # Summary-keyword overlap
    kws = summary_keywords(model_summary)
    hits = [kw for kw in kws if kw in t]
    return len(hits) >= 2


def detect_disallowed_theme_hits(text: str, profile: Dict[str, Any]) -> List[str]:
    disallowed = get_disallowed_themes(profile)
    return find_present_phrases(text, disallowed)


def detect_extension_concepts_in_core_mode(text: str, profile: Dict[str, Any]) -> List[str]:
    all_concepts = all_extension_concepts(profile)
    # Focus on exact extension concept phrases, not every single token
    return find_present_phrases(text, all_concepts)


def detect_cross_family_extension_ids(
    used_extension_ids: Set[str],
    profile: Dict[str, Any],
    family_name: str
) -> List[str]:
    allowed = family_identifier_set(profile, family_name)
    return sorted([x for x in used_extension_ids if x not in allowed])


def validate_gate2(
    question: str,
    answer: str,
    mode: str,
    profile: Dict[str, Any],
    family_name: str = None,
    global_allow: Set[str] = None
) -> Dict[str, Any]:
    """
    Mode-aware Gate 2 validator.

    Parameters
    ----------
    question, answer : str
        Generated QA content.
    mode : str
        One of: "core_paraphrase", "core_repair", "anchored_extension".
    profile : dict
        Model profile with "core" and optional "extensions".
    family_name : str, optional
        Required for focused anchored_extension validation.
    global_allow : set, optional
        Global NetLogo terms allowed in backticks.

    Returns
    -------
    dict
        Example:
        {
          "ok": True/False,
          "reason": None or "CODE",
          "details": {...}
        }
    """
    if global_allow is None:
        global_allow = DEFAULT_GLOBAL_ALLOW

    text = f"{question}\n{answer}"
    text_n = norm(text)

    core = profile["core"]
    core_ids = build_core_identifier_set(core)
    ext_ids_all = all_extension_identifiers(profile)
    summary = core.get("model_summary", "")

    backticked = set(extract_backticked_identifiers(text))
    used_core_ids = {x for x in backticked if x in core_ids}
    used_ext_ids = {x for x in backticked if x in ext_ids_all}
    unknown_ids = {
        x for x in backticked
        if x not in core_ids and x not in ext_ids_all and x not in global_allow
    }

    # 1) Hard unknown identifier check
    if mode in {"core_paraphrase", "core_repair"}:
        if unknown_ids:
            return {
                "ok": False,
                "reason": "UNKNOWN_CORE_IDENTIFIER",
                "details": {
                    "unknown_identifiers": sorted(unknown_ids),
                    "used_core_ids": sorted(used_core_ids),
                    "used_extension_ids": sorted(used_ext_ids)
                }
            }

        # In core mode, any extension identifier is disallowed
        if used_ext_ids:
            return {
                "ok": False,
                "reason": "UNAPPROVED_EXTENSION_IDENTIFIER",
                "details": {
                    "extension_identifiers_in_core_mode": sorted(used_ext_ids)
                }
            }

        # Optional: catch exact extension concept phrases in plain text
        ext_concept_hits = detect_extension_concepts_in_core_mode(text, profile)
        if ext_concept_hits:
            return {
                "ok": False,
                "reason": "EXTENSION_CONTENT_IN_CORE_MODE",
                "details": {
                    "extension_concept_hits": ext_concept_hits[:20]
                }
            }

        disallowed_hits = detect_disallowed_theme_hits(text, profile)
        if disallowed_hits:
            return {
                "ok": False,
                "reason": "DISALLOWED_THEME",
                "details": {
                    "disallowed_hits": disallowed_hits
                }
            }

        return {
            "ok": True,
            "reason": None,
            "details": {
                "used_core_ids": sorted(used_core_ids),
                "used_extension_ids": []
            }
        }

    elif mode == "anchored_extension":
        if unknown_ids:
            return {
                "ok": False,
                "reason": "UNAPPROVED_EXTENSION_IDENTIFIER",
                "details": {
                    "unknown_identifiers": sorted(unknown_ids),
                    "used_core_ids": sorted(used_core_ids),
                    "used_extension_ids": sorted(used_ext_ids)
                }
            }

        # If family-specific validation is active, reject extension identifiers from other families
        if family_name:
            cross_family_ids = detect_cross_family_extension_ids(used_ext_ids, profile, family_name)
            if cross_family_ids:
                return {
                    "ok": False,
                    "reason": "CROSS_FAMILY_EXTENSION_IDENTIFIER",
                    "details": {
                        "family_name": family_name,
                        "cross_family_extension_ids": cross_family_ids
                    }
                }

        # If any extension IDs are used, require framing
        if used_ext_ids and not has_extension_framing(answer, profile):
            return {
                "ok": False,
                "reason": "EXTENSION_REQUIRES_FRAMING",
                "details": {
                    "used_extension_ids": sorted(used_ext_ids)
                }
            }

        # Reject if extension IDs are falsely described as built-in to base model
        misrep = implies_base_model_contains_extensions(answer, used_ext_ids)
        if misrep:
            return {
                "ok": False,
                "reason": "BASE_MODEL_MISREPRESENTATION",
                "details": {
                    "misrepresented_extension_ids": misrep
                }
            }

        # Require some anchor to the original model
        if not has_core_anchor(text_n, core_ids, summary):
            return {
                "ok": False,
                "reason": "INSUFFICIENT_CORE_ANCHOR",
                "details": {
                    "used_core_ids": sorted(used_core_ids),
                    "model_summary": summary
                }
            }

        disallowed_hits = detect_disallowed_theme_hits(text, profile)
        if disallowed_hits:
            return {
                "ok": False,
                "reason": "DISALLOWED_THEME",
                "details": {
                    "disallowed_hits": disallowed_hits
                }
            }

        return {
            "ok": True,
            "reason": None,
            "details": {
                "used_core_ids": sorted(used_core_ids),
                "used_extension_ids": sorted(used_ext_ids),
                "family_name": family_name
            }
        }

    else:
        return {
            "ok": False,
            "reason": "UNKNOWN_MODE",
            "details": {"mode": mode}
        }
```

# How to integrate this into your pipeline

Use it right after parsing the LLM response JSON.

## Example integration

```python
def run_gate2(parsed_obj, route_result, profile):
    question = parsed_obj["question"]
    answer = parsed_obj["answer"]
    mode = route_result["route"]

    # map core_repair to same validator mode logic
    if mode == "core_repair":
        mode_for_validator = "core_repair"
        family_name = None
    elif mode == "core_paraphrase":
        mode_for_validator = "core_paraphrase"
        family_name = None
    elif mode == "anchored_extension":
        mode_for_validator = "anchored_extension"
        family_name = route_result.get("family")
    else:
        return {
            "ok": False,
            "reason": "UNEXPECTED_ROUTE_FOR_GATE2",
            "details": {"route": mode}
        }

    return validate_gate2(
        question=question,
        answer=answer,
        mode=mode_for_validator,
        profile=profile,
        family_name=family_name
    )
```

# One caution

This validator is intentionally **conservative on backticked identifiers** and **lighter on plain-English concept policing**.

That is a good default because:

- backticks are where your LLM most often makes concrete false claims
- plain-English concept policing can become over-aggressive and reject good scientific language

If you later want stricter concept checks, add them gradually and only after reviewing false rejects.
